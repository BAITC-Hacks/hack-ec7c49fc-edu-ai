# Demo queries

These queries map to objectives currently supported by the deterministic optimizer.

1. `improve_district` with social focus and critical reduction:

   > Улучши Нуру и убери критические социальные показатели, не выходя за бюджет 100.

2. `maximize_city_score`:

   > Максимизируй общий Astana Quality of Life Score.

3. `balanced_development`:

   > Предложи более сбалансированный сценарий, чтобы не оставить слабый район.

If OpenAI is unavailable, the deterministic parser recognizes the district, critical/social, maximize, and balanced intent used in these examples.
